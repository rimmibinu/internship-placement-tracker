# Wireframes (text)

**Login** – centred card: email field, Sign-in button, demo-account chips.

**Dashboard (admin)** – stat tiles (students, companies, open roles, applications, offers, placement rate) · [Status bars | By company table] · [Closing soon list | Department report].
**Dashboard (student)** – tiles (applications, shortlisted, interviews, offers) · [My latest applications | Closing soonest].

**Opportunities** – filter bar (search, type, company, open-only) · responsive grid of cards (badges, pay, min CGPA, deadline, openings) · admin "+ New".

**Opportunity details** – [Details + criteria | Student: eligibility banner + cover note + Apply / status + Withdraw ; Admin: Edit / Close / Delete] · Admin: applicants table with status buttons and remarks.

**Opportunity form** – grid of fields, department checkboxes, validation messages under each field.

**Companies / Students** – "+ Add" opens inline form · search/filter bar · table with Edit/Delete.

**Applications** – filter bar · table (student, role, applied, status, remarks, actions).
